# Salesforce Opportunity Analysis

This project is an R Markdown analysis of 1,272 Salesforce opportunities created on or after January 1, 2024, representing $397.2M in total value. The analysis explores pipeline composition, opportunity creation trends, closed-won performance, sales cycle timing, and advisor-level results to identify both strengths and areas for improvement. Key findings show a large early-stage pipeline, a 91.8% win rate across closed opportunities, stronger sales activity in 2025, and much faster close times for won deals than lost deals.
